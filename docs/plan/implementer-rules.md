# Rules for every card

You are given one task card. Do what it says, and nothing else.

1. Change only the files listed under **Files**. Create no other file.
2. Read only what is listed under **Read first**. Do not explore the repository.
3. Follow the card's **Steps** in order. Where a step gives code, names or wording, use them
   exactly. A recipe under **Read first** (a file in `docs/plan/patterns/`) shows how work of
   this kind is done. Where it and the card differ, follow the card.
4. Do not edit a test you were given. Do not edit a generated file. Do not edit a migration that
   already exists.
5. Do not add a feature, an option, a field, a comment about your work, or a dependency that the
   card does not ask for.
6. Write the tests the card names under **Tests**, with the names it gives.
7. Ignore the **Audit** section. It is for the person who checks your work.
8. Patient data in code and tests is made up: invented names, descriptions that start with
   "Demo:". Never a real-looking phone number, address or ID number.
9. Text a user reads is copied from the card exactly, with its curly apostrophes.
10. Do not commit, push or switch branches. Leave your changes in the working tree.
11. When you are done, reply with: the files you changed, and the last line each command under
    **Run** printed.
12. Stop and say what happened, without guessing, if: a step is unclear; the code is not as the
    card describes it; a command fails twice with the same message.
