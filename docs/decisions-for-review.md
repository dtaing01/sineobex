# Decisions for review

Every choice the build has left to a person, in one place. The project lead's rule of Nov 21 is
that nothing is asked of a person mid-build: wherever a choice needs one, the default is built,
marked `PLAN-OPEN` in the code where the PRD leaves it open, and listed here with who decides, the
default built, a recommendation, what a later change would cost and where it lives. This version
describes the code at commit `c307a0b`, with phases 0 to 4 built and closed; phases 5 to 12 are
designed, and each design's own defaults join this document as its phase closes. Read "Decide
early" first, then your own section, and answer by row id: a row nobody answers keeps its default.
It holds 118 decisions: 10 for the project lead, 63 for Brooke and Mercy, 12 for counsel and 33
for the team, each naming in its Decision anyone else to ask. "Before the first real patient" lists
what needs a person or an account but no decision.
